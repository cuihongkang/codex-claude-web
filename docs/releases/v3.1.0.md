# Codex Web v3.1.0

- 消息输入框支持直接编辑 Markdown 排版，输入标题、列表、加粗等语法后自动排版，可直接修改表格；公式统一使用 `$$公式$$`，闭合后在当前段落内显示并可继续正文，单美元符号保留普通文本。正文保持两行固定高度，长文本内部滚动，滚动、缩放及编辑器加载后的光标和选区保持准确。（[5af0fdd](https://github.com/hjd-hitsz/codex-web/commit/5af0fdd)）
- 桌面打开文件及变更详情时，输入框随左侧对话收窄，文件详情可使用完整高度，下载入口整合为文件工具栏图标。（[990b4a8](https://github.com/hjd-hitsz/codex-web/commit/990b4a8)）
- 打开超长对话时先显示最近消息并恢复输入，其余历史自动补齐；补齐期间保留向上翻阅的位置，减少等待和重复渲染。（[75d6dc1](https://github.com/hjd-hitsz/codex-web/commit/75d6dc1)）
- 手动整理上下文时，在输入框上方统一显示整理状态与耗时；完成提示在关闭、切换对话或重新打开网页后保持收起，进行中的整理继续恢复。（[01280f6](https://github.com/hjd-hitsz/codex-web/commit/01280f6)、[83f915e](https://github.com/hjd-hitsz/codex-web/commit/83f915e)）
- 添加或编辑回复批注时，按 Enter 完成当前批注，Shift+Enter 换行，中文输入法确认选词时继续编辑。（[e1a93a2](https://github.com/hjd-hitsz/codex-web/commit/e1a93a2)）
- 点击账户额度圆环后，详情显示可购买的额外点数余额，最多保留两位小数，并随额度更新。（[cb9336a](https://github.com/hjd-hitsz/codex-web/commit/cb9336a)）
- 子代理详情中的加密消息在等待接收时立即显示“消息内容已加密”。（[42b96e0](https://github.com/hjd-hitsz/codex-web/commit/42b96e0)）
- 侧栏优先显示钉选项目，空项目和没有活跃对话的钉选项目也保持在未钉选项目之前。（[4c2d996](https://github.com/hjd-hitsz/codex-web/commit/4c2d996)）
