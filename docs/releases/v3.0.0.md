# Codex Web v3.0.0

- 增加系统账户网页登录与退出入口，登录状态默认保留 30 天，刷新网页、重新打开浏览器和重启服务后可恢复有效登录；退出或登录过期时保留未发送草稿及已提交任务，支持浏览器自动填充和登录后保存密码。（[22ff961](https://github.com/hjd-hitsz/codex-web/commit/22ff961)）
- 网页改用 HTTPS 访问，支持自动生成本站证书或使用自有证书，登录页与设置页提供证书下载和设备安装指引。（[22ff961](https://github.com/hjd-hitsz/codex-web/commit/22ff961)）
- 侧栏文件夹支持固定与取消固定，固定后即使全部对话已归档，刷新或重新打开网页仍保留文件夹和新建对话入口；打开网页时固定文件夹默认展开，其余默认折叠，“未分类”保持在底部，每组先显示最新 5 个对话，可通过“查看更多”展开全部。（[91b8b33](https://github.com/hjd-hitsz/codex-web/commit/91b8b33)）
- 文件编辑器与终端在首次使用时加载，减少进入聊天页面时需要下载的内容。（[b4638d6](https://github.com/hjd-hitsz/codex-web/commit/b4638d6)）
- 精简登录、设置与子代理详情中的说明，“关于”页显示产品版本，保留使用时需要的状态与操作。（[22ff961](https://github.com/hjd-hitsz/codex-web/commit/22ff961)）
- 子代理详情补齐主代理发送的初始任务和后续消息，标明发送者，并随刷新和实时活动更新；加密记录显示“消息内容已加密”。（[c9483fd](https://github.com/hjd-hitsz/codex-web/commit/c9483fd)）
- 上下文整理完成后，发送新消息会自动关闭完成提示。（[d43c9fe](https://github.com/hjd-hitsz/codex-web/commit/d43c9fe)）
