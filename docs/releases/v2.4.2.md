# Codex Web v2.4.2

- 按项目记住上次选择的模型和思考强度，同项目新建对话沿用当前选择，更换浏览器或清除站点数据后可恢复项目设置；切换模型时保留当前思考强度，目标模型缺少该档位时选择最接近的可用档位。（[7885a6a](https://github.com/hjd-hitsz/codex-web/commit/7885a6a)）
- 侧栏对话时间靠右显示，鼠标悬浮标题行时显示归档与更多按钮，键盘和触屏继续可用；运行中显示旋转圆圈，本页任务完成且尚未阅读时显示绿色圆点，阅读后清除，刷新或重新打开页面时清空提示。（[c7e8597](https://github.com/hjd-hitsz/codex-web/commit/c7e8597)）
- 新建或切换对话时收起右侧详情，文件与差异视图随所属对话显示，保留原对话中尚未保存的文件编辑。（[1fa4488](https://github.com/hjd-hitsz/codex-web/commit/1fa4488)）
- 侧栏按轮次开始与结束的最近活动时间排序并显示时间，修复新一轮运行时仍按上一轮结束时间排列的问题；打开或重命名对话保持活动顺序。（[511f9ce](https://github.com/hjd-hitsz/codex-web/commit/511f9ce)）
- 修复长对话中输入文字时的卡顿，改善语音输入一次写入大段文字及后续编辑的响应速度。（[10612e0](https://github.com/hjd-hitsz/codex-web/commit/10612e0)）
- 文件与目录引用以类型图标和蓝色链接显示，点击后在右侧查看文件或浏览目录；批注原文默认收起，消息、复制和编辑显示可读内容，编辑后保留引用与批注供统一重新发送。（[7e2f781](https://github.com/hjd-hitsz/codex-web/commit/7e2f781)）
