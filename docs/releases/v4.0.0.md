# Claudex Web v4.0.0

- 新增 Codex 与 Claude Code 双后端，在同一模型菜单选择 ChatGPT 或其他供应商的模型；Claude 对话支持计划与批准、编辑、分支、目标、后台终端及子代理详情，空闲时可切换供应商继续对话。（[37209e4](https://github.com/hjd-hitsz/claudex-web/commit/37209e4)）
- Claude Code 可使用项目中的原生命令、技能、插件和工具连接，显示原生账户额度或外部供应商身份；刷新及网页服务重启后可继续查看已提交任务和后台终端的执行结果。（[37209e4](https://github.com/hjd-hitsz/claudex-web/commit/37209e4)）
- 预置 DeepSeek 供应商，填写 API Key 即可启用；供应商列表优先展示默认项及品牌图标，自定义模型可设置简短的显示别名。（[79ff9f1](https://github.com/hjd-hitsz/claudex-web/commit/79ff9f1)、[78386ab](https://github.com/hjd-hitsz/claudex-web/commit/78386ab)）
- 设置页支持直接启停两个后端，展示 CLI 安装状态、当前及最新版本，并提供一键安装、更新和失败重试；停用后所属对话立即从列表隐藏，重新启用后恢复。（[2c455dc](https://github.com/hjd-hitsz/claudex-web/commit/2c455dc)、[832b202](https://github.com/hjd-hitsz/claudex-web/commit/832b202)）
- 产品更名为 Claudex Web，命令及网页配置目录同步更新，首次升级继承原有网页配置、证书、登录状态和项目偏好。（[e6330ea](https://github.com/hjd-hitsz/claudex-web/commit/e6330ea)、[03634b2](https://github.com/hjd-hitsz/claudex-web/commit/03634b2)）
- 改善双后端的历史恢复、模型选择、思考正文与用量显示，用户消息支持 Markdown 和文件引用，文件与目录可模糊查找；列表读取失败时保留已有内容并提供重试。（[03634b2](https://github.com/hjd-hitsz/claudex-web/commit/03634b2)）
- 设置页使用更清晰的分区标题，登录状态与退出按钮同行显示，模型和服务配置及供应商列表直接展开。（[044814d](https://github.com/hjd-hitsz/claudex-web/commit/044814d)）
- 修复 Codex 对话打开网页终端失败的问题，终端按运行环境选择登录 shell。（[4aeb07b](https://github.com/hjd-hitsz/claudex-web/commit/4aeb07b)）
- 输入区支持文件、目录、技能和同后端会话的行内引用，支持技能模糊搜索、删除、撤销与草稿恢复。（[ed38abe](https://github.com/hjd-hitsz/claudex-web/commit/ed38abe)）
- Claude Code 设置支持跟随服务环境、关闭代理或配置 HTTP 代理，供联网工具使用。（[2b98268](https://github.com/hjd-hitsz/claudex-web/commit/2b98268)、[acbaa3f](https://github.com/hjd-hitsz/claudex-web/commit/acbaa3f)）
- Codex 可选择模型菜单中显示的模型；DeepSeek 账户行可查看余额、赠金和充值余额，并自动更新。（[606cd71](https://github.com/hjd-hitsz/claudex-web/commit/606cd71)）
- 文件、差异和子代理详情可拖动调宽，弹窗、图片及批注预览支持尺寸调节、键盘操作和尺寸记忆。（[78e52f0](https://github.com/hjd-hitsz/claudex-web/commit/78e52f0)）
- 终端支持持续新建独立进程，名称与图标跟随前台程序；按启动文件夹保留进程和选择，支持调节高度及列表宽度，并修复最后一个终端退出后的空面板。（[8ff46ee](https://github.com/hjd-hitsz/claudex-web/commit/8ff46ee)）
- 文件夹选择器默认隐藏点开头的目录，可勾选显示隐藏文件夹。（[bd58499](https://github.com/hjd-hitsz/claudex-web/commit/bd58499)）
- 输入框附件可按格式预览图片、文本、音视频和 PDF；压缩包及其他二进制文件保留原始内容，提供文件信息与下载，发送后可供代理读取。（[0c49456](https://github.com/hjd-hitsz/claudex-web/commit/0c49456)）
- 子代理完成时省去系统完成提醒，再次接收任务后恢复运行状态；Claude 历史中的原生中断记录正确归类。（[af0120b](https://github.com/hjd-hitsz/claudex-web/commit/af0120b)、[5ec54b3](https://github.com/hjd-hitsz/claudex-web/commit/5ec54b3)）
- 修复快速重新打开 Codex 对话或编辑重发时遇到会话关闭错误的问题；Claude 项目模型偏好同步到其他页面，失效模型显示不可用状态。（[5530bc1](https://github.com/hjd-hitsz/claudex-web/commit/5530bc1)）
- 计划方案支持预览、展开、批准执行和继续修改，批准后自动切换执行模式；已有对话保留自身模型与思考强度，链接后的空格恢复普通正文。（[84c1abf](https://github.com/hjd-hitsz/claudex-web/commit/84c1abf)、[479de3d](https://github.com/hjd-hitsz/claudex-web/commit/479de3d)、[70bc162](https://github.com/hjd-hitsz/claudex-web/commit/70bc162)）
